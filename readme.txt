-- VALIDATION NOTES --

1. CSS validation produced errors within the generated Next.js/Tailwind production stylesheet, primarily involving modern CSS features such as @property, generated custom properties, and newer properties not recognized by the W3C CSS Level 3 validator. These styles are generated by the framework rather than handwritten CSS and render correctly in current browsers. I reviewed the output and did not identify these reports as user-facing layout or accessibility problems.
2. HTML validation reports several informational notices regarding trailing slashes on void elements and one error involving a framework-generated script appearing after the closing HTML element. These elements are generated by the Next.js/React production build rather than handwritten markup. The page renders and functions correctly in modern browsers, so I documented the validator result rather than modifying framework-generated output immediately before submission.
